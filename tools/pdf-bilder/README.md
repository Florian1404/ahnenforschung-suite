# Bilder aus Stammbaum-PDFs extrahieren

**Start:** `py stammbaum_bilder.py` im PDF-Ordner.

`py -m pip install --upgrade pymupdf`.

Die Quelle `stammbaum_bilder_NEU.py` nutzt Text-/Positionsdaten und heuristische Bildzuordnung ohne OCR. Ergebnisse müssen überprüft werden. Keine echten Familien-PDFs committen.
